## Decisions and discrepancies

- Episode 1 is locked on Patreon while Episodes 2–6 are public. The website
  treats it as public so the serial has a coherent reading order. Its Patreon
  access setting should be corrected separately.
- Episode 7 is the current Patreon-ahead installment and is not generated into
  the public reader.
- Patreon prose and the current Obsidian manuscripts contain revision
  differences. The website uses the Obsidian files as canonical rather than
  copying older text back from Patreon.
- The canonical public title is **The Garnet Shield**. Patreon copy that calls
  the book `Bloodline: Garnet` should eventually be standardized.
- Episodes 5–7 do not yet have subtitles in the Patreon catalog.
- Patreon posts containing a Markdown scene divider may display the literal
  text `---`; future posting should convert dividers to Patreon's native rule
  or another deliberate ornament.
