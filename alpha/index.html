Bloodline Alpha

Reader portal for draft scenes, revisions, and rough-cut pages.

This static gate is meant for low-friction alpha sharing on GitHub Pages. It hides the scene hub behind a password prompt, but it is not full server-side protection.

Fast access

Readers land directly in the scene index after sign-in.

Unlisted by default

Portal and scenes are marked noindex and are not linked from the homepage.

Easy to update

Swap the stored password hash once you decide the real alpha-reader passphrase.

Enter the portal

Default placeholder password is still configured. Change it before sending this page to readers.

Static-site note

This is suitable for casual reader gating. If you need true protection, the files need to move behind server auth or a gated platform.
